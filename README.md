# Bihar Heritage | बिहार धरोहर

**Live:** https://sanjay289.github.io/bihar-heritage/

An educational website and installable app about Bihar's places, great people, culture and all 38 districts.

- 5 languages: Hindi, English, Bhojpuri, Maithili, Magahi
- 36 topic cards with real photos, 38 districts in 9 divisions
- 54-question quiz (Easy / Hard / Mixed) with best scores
- Works offline and can be added to the home screen

Photos come from Wikimedia Commons under free licences. See the "Photo credits" page in the app.
